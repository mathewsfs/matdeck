    Dispositivos (acesso ao deck)

    Este gerenciador só abre no computador onde o MatDeck está rodando. Um tablet ou celular que abrir o deck pela rede pede um PIN de 4 dígitos, que aparece no canto desta tela; digitado uma vez, o aparelho fica lembrado. Remova um aparelho para que ele volte a pedir PIN.

    Auto-Perfil (troca pela janela em foco)

    O botão AUTO da barra liga e desliga a troca automática. O MatDeck nasce com ele desligado e lembra o último estado. Abaixo, escolha o perfil que cada aplicativo ativa quando sua janela ganha o foco, ou "Não trocar" para ignorá-lo.

    OBS Studio

    Em OBS: Ferramentas > Configurações do Servidor WebSocket.

    TeamSpeak

    No TS5/TS6 ative Configurações > Remote Apps e autorize o MatDeck quando o aviso aparecer.

    Vazio: o MatDeck pede autorização e guarda a chave sozinho.

    Discord

    Controle nativo (mic, surdo e PTT funcionam com o Discord na bandeja): crie um aplicativo em discord.com/developers/applications, em OAuth2 adicione o redirect http://localhost e copie o Client ID e o Client Secret para cá. Depois de salvar, aceite a janela que o Discord abre.

    Sem Client ID: controle por atalhos de teclado.

    Usado só sem a API ou com o Discord em modo Push to Talk. Configure o mesmo atalho em Discord > Configurações > Teclas de atalho.

    Google Meet

    Uso de IA (Claude Code / Codex CLI)

    As teclas "Uso de IA" leem as credenciais que o Claude Code e o Codex CLI já guardam neste usuário e consultam as mesmas APIs de uso que o plugin "Claude & Codex Usage" da Elgato, sem precisar do plugin. Cores: verde, âmbar a partir de 70% e vermelho a partir de 90%. Um toque na tecla atualiza na hora.

    Ventoinhas (CoolerControl)

    O fader "Ventoinhas" usa o daemon do CoolerControl (porta 11987) para colocar todas as ventoinhas controláveis na mesma velocidade fixa; um toque devolve cada uma à curva/perfil que tinha. Bombas de water cooler são ignoradas pelo padrão acima. Em CoolerControl 5 a API exige um access token (Configurações → Access Tokens, na GUI); se o campo ficar vazio, o MatDeck usa o token que a GUI já guardou neste usuário.

    Nextcloud Talk

    As teclas enviam os atalhos do próprio Talk (M microfone, V câmera, R mão, F tela cheia) para a janela em foco, no navegador ou no app Nextcloud Talk. O Talk não tem API para ler o estado do microfone, por isso o estado nas teclas é otimista; "Reiniciar estado" realinha.

    Plugins do Stream Deck

    Arraste um .streamDeckPlugin aqui ou envie o arquivo. No Marketplace da Elgato o download exige login na conta Elgato (gratuita); plugins open source têm o arquivo nas releases do GitHub. Só plugins em Node.js rodam aqui (plugins nativos de Windows/macOS não funcionam no Linux).
